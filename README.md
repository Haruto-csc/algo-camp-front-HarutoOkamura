# algo-camp-front

`algo-camp` のフロントエンドアプリケーションです。

## 開発環境 / 技術スタック

- **フレームワーク:** Next.js 15.5.18 (App Router)
- **ライブラリ:** React 19.0.0, Tailwind CSS, Shadcn/ui, Lucide React
- **データベース接続/ORM:** Drizzle ORM, Neon Database
- **認証:** NextAuth.js (v5 beta)
- **パッケージマネージャー:** pnpm
- **Node.js バージョン:** v18.19.0

## ローカル環境での起動方法

### 1. 依存関係のインストール

```bash
pnpm install
```

### 2. 開発サーバの起動

```bash
pnpm dev
```
